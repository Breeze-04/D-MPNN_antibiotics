# D-MPNN_antibiotics
Antibiotics MIC Prediction, for E. coli


### topic
For the Homerton Cambridge Summer School on "Frontier Theories and Applications in Materials Science and Artificial Intelligence": Chemprop, as used in *A Deep Learning Approach to Antibiotic Discovery*, was originally designed for antibiotic classification tasks. However, with its subsequent development, Chemprop has become a general-purpose software for molecular property prediction. In the original paper, the dataset used to train Chemprop was too small and, due to iterations of Chemprop, is no longer reproducible. Accordingly, building on *A Deep Learning Approach to Antibiotic Discovery* and Chemprop, we plan to collect new data and create some usage examples.
